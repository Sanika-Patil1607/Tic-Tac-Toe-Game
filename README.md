# 🎮 Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.  
This project demonstrates basic front-end development concepts and game logic implementation.

---

## 🚀 Features

- 🧑‍🤝‍🧑 Two-player mode (Player X vs Player O)
- 🎯 Real-time win detection
- 🤝 Draw detection
- 🔄 Restart / New Game functionality
- 💡 Simple and user-friendly UI

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript (Vanilla JS)

---

Tic-Tac-Toe-Game/

---

## ▶️ How to Play

1. Player X starts the game.
2. Players take turns clicking on empty boxes.
3. First player to align 3 marks (row, column, diagonal) wins.
4. If all boxes are filled and no winner → it's a draw.
